01 · Platform

플랫폼 구축

고객 앱과 기사 앱(iOS 네이티브), API 서버, 클라우드 인프라를 처음부터 직접 설계하고 구축했습니다.

02 · Operations

운영 구조 개선

분쟁이 잦던 취소·추가 대기·경로 변경 요금을 규칙으로 표준화하고, 기사 정산을 주 단위로 자동화했습니다.

03 · Matching

위치 기반 매칭

거리 반경별 콜 노출, 즉시·예약·맞춤 콜 구분, 공간 데이터베이스를 이용한 위치 질의를 설계했습니다.

04 · Architecture

IT 시스템 설계

이벤트 처리 구조와 실시간 통신을 설계하고, 인프라 코드화와 자동 배포로 운영 가능한 시스템을 만들었습니다.

05 · UI/UX

화면·앱 개발

자체 디자인 시스템을 만들고, 고객·기사 화면과 지도 연동을 사용자 흐름 중심으로 설계했습니다.

06 · Data

데이터 기반 설계

운행·위치·정산 데이터를 하나의 모델로 묶고, 요금·근무 시간 규칙을 코드로 검증했습니다.

07 · Agile

작은 팀의 빠른 개발

AI 개발 도구를 활용한 소규모 구조로 60회가 넘는 짧은 개발 주기를 반복하고, 결정을 문서로 남겼습니다.
